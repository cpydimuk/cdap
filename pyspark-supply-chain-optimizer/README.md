# PySpark Supply Chain Optimizer

A PySpark-based pipeline for supply chain planning: demand forecasting,
multi-echelon inventory optimization, network/distribution optimization,
and production/procurement planning.

This project is currently in the **design phase** — no implementation
yet. See:

- [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) — scope, use cases,
  functional and non-functional requirements, acceptance criteria.
- [`docs/DESIGN.md`](docs/DESIGN.md) — architecture, key decisions,
  data schemas, module layout, and testing strategy.

Implementation will follow once the design decisions in
`docs/DESIGN.md` §9 are confirmed.
